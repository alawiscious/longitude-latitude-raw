# Art Basel 2026 Tables

Password-protected static copy of the Art Basel Miami 2026 table-booking dashboard (Dec 3–5, 2026).

The page is encrypted client-side with [StatiCrypt](https://github.com/robinmoisson/staticrypt); nothing readable is stored in this repo. Open the GitHub Pages URL and enter the password.

Rebuilt by hand when quotes change; the date stamp is at the bottom of the page.
